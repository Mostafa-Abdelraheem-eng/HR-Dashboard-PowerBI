# 📊 HR Analytics & Performance Dashboard

An interactive Human Resources (HR) Business Intelligence dashboard built using **Microsoft Power BI** to analyze employee demographics, salaries, bonuses, and performance scores across departments and cities.

---

## 🚀 Project Overview
This project provides deep insights into workforce metrics to help HR decision-makers evaluate employee distribution, salary allocations, and performance evaluations. The dashboard features two main pages covering geographical distribution, departmental breakdowns, and performance analytics.

---

## 📈 Key Dashboard Insights & Metrics
* **Total Salaries:** Tracked across the organization (reaching **1.94M** in total salary expenditure).
* **Geographical Distribution:** Visualizes bonuses and employee distribution across major cities (**Asyut, Cairo, Alexandria, Luxor, Giza**).
* **Departmental Breakdown:** Analyzes **HR, IT, Operations, Marketing, and Finance** departments by headcount, salary, and performance scores.
* **Performance vs. Salary Analysis:** Evaluates how salary distribution correlates with employee performance scores.

---

## 🛠️ Tools & Technologies
* **Power BI:** Data modeling, DAX measures, and interactive visualizations.
* **Power Query:** Data cleaning, transformation, and ETL processes.
* **Microsoft Excel:** Raw dataset source (`hr_dataset.xlsx`).
